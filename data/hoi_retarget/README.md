# Object pushing — G1 with ball hands

Four 50 Hz motion/video pairs with moving-object meshes, object pose trajectories,
source contact labels, and floor geometry. Each directory contains a reproducible
source record and geometry review. Videos are Isaac Lab kinematic replay of the
exported NPZ, not physics rollouts.
